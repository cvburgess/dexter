# Supabase (`/supabase`)

Deno Edge Functions (`functions/`), ordered SQL migrations (`migrations/`), and
Supabase CLI configuration for Dexter.

Everything about this directory — function behavior, RLS invariants, migrations,
secrets, deployment — lives in [`../docs/backend.md`](../docs/backend.md).
Commands are in [`../AGENTS.md`](../AGENTS.md). `supabase start` requires
Docker.
