# Lists

Lists are a simple, visual way to organize tasks any way you see fit: a list for
work, a list for chores, a list for hobbies, a list for each project. Each list
gets an emoji you choose, so you can spot it at a glance.

**Note**: A task belongs to one list at a time, or to none.

## Managing lists

Open **Settings → Lists** to see every list and how many open tasks it holds.

- <i class="ph-bold ph-plus"></i> **New list**: Pick an emoji and give it a name
- **Edit**: Tap a list to change its emoji or name
- **Archive**: Archiving a list hides it and marks its open tasks as won't do

## Adding a task to a list

Every task card has a list button. Tap it to pick a list, or choose **None** to
take the task off its list. You can also pick a list while creating a task.

## Lists View

On a larger screen (an iPad, a Mac, or a wide browser window), the **Lists** tab
shows your open tasks as a board, with one column per list.

- **Drag a task** from one column to another to move it to that list
- **No List** appears first whenever an open task isn't on a list; drag tasks
  out of it to sort them
- <i class="ph-bold ph-plus"></i> **New list**: Add a list without leaving the
  board

Completed tasks stay off the board, so it only shows what's still left to do.
